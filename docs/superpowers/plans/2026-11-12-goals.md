# goals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild goals as a multi-user web app with daily SMS check-ins on go-template standards, deployed at goals.timeclimbers.com on mist.

**Architecture:** One Go binary: chi router serving `html/template` pages and a Twilio webhook, GORM on Postgres, and an in-process minute ticker that sends reminders. Twilio sits behind small interfaces so everything is testable with fakes.

**Tech Stack:** Go 1.27.3, chi v5, go.icco.me/gutil (logging), GORM + postgres driver, github.com/twilio/twilio-go v1.33.0, Postgres 18.

**Spec:** `docs/superpowers/specs/2026-11-12-goals-design.md`

## Global Constraints

- Module `go.icco.me/goals`, `go 1.27.3`, branch `main`.
- Every exported identifier has one doc comment starting with its name. No other comments except a one-line non-obvious why.
- Lint with the committed `.golangci.yml` from go-template; coverage floor 80% (`COVERAGE_THRESHOLD: "80"`).
- Tests use `lib/dbtest` against `postgres://postgres:postgres@localhost:5432/goals_test?sslmode=disable`, and fictional numbers such as `+15555550100`.
- Dates are user-local `YYYY-MM-DD` strings. Default timezone `America/New_York`, default reminder minute `1200` (20:00), max 10 active goals, goal text 1-140 runes after trimming.
- Signup accepts only `+1` followed by 10 digits after normalization.
- Never text a user who is paused or opted out, or who has no active goals.
- Env: `PORT` (default 8080), `DATABASE_URL`, `BASE_URL`, `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_MESSAGING_SERVICE_SID`, `TWILIO_VERIFY_SERVICE_SID`. With any Twilio var unset, the app starts, logs a warning, and SMS features return `sms.ErrDisabled`.

## Review Focus

- Reply arrives after the user edited or archived goals: numbers map to the reminder's stored `GoalIDs`; archived goals still get recorded.
- Timezone edge: a user in `Pacific/Honolulu` at 23:30 local on a UTC date that's already tomorrow gets today's local date (test in Task 5).
- Duplicate tick or two instances: `ClaimReminder` returns `claimed=false` for the second call and nothing is sent twice (test in Task 5).
- Forged webhook: a POST to `/sms` with a bad `X-Twilio-Signature` gets 403 and writes nothing (test in Task 8).
- A phone that never consented tries `/login`: no account is created and no code is sent (test in Task 6).

### Task 8: SMS webhook

**Files:** Create `lib/web/webhook.go`, `lib/web/webhook_test.go`.

`POST /sms`: validates `X-Twilio-Signature` against `BaseURL + "/sms"` and the form params (403 when invalid). `OptOutType` `STOP` -> `SetOptedOut(true)`, `START` -> false, `HELP` -> no state change; all three reply with empty `<Response/>`. Unknown `From` -> empty `<Response/>`. Otherwise use `LatestReminder` + `GoalsByID` + `ParseReply`, then `SetCheckIn` per goal with source `sms` on the reminder's date. Reply TwiML `<Response><Message>Saved: 2 of 3 done for Nov 12.\nStreaks: read 20 pages 5, run 0</Message></Response>`. On ErrUnparsed, reply with the last line of `remind.Message`. With no reminder yet, reply `No check-in to answer yet.`. Content-Type `text/xml`; escape with `encoding/xml`.
